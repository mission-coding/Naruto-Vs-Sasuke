# Naruto vs Sasuke 🍥⚔️

A Naruto-themed fighting game built with Python and Pygame. Move your character, jump, launch projectile attacks, and battle using character animations and health bars.

## ✨ Features

- Naruto-themed character sprites and animations
- Player movement and jumping
- Projectile-based attacks
- Health bars and hit detection
- Background and ground graphics
- Sound effects
- Round-ending and restart functionality

## 🕹️ Controls

| Key | Action |
|---|---|
| Left Arrow | Move left |
| Right Arrow | Move right |
| Up Arrow | Jump |
| Space | Throw a projectile |
| Enter | Restart when the round ends |

## 🛠️ Technologies Used

- Python
- Pygame

## 🚀 How to Run

1. Install Python 3.
2. Install Pygame:

   ```bash
   python -m pip install pygame
   ```

3. Run the game:

   ```bash
   python fight.py
   ```

## 📁 Project Structure

- `fight.py` — Main game file
- `pics/` — Character sprites and other game assets

Keep the `pics/` folder alongside the Python file.
